# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A parametric 3D-printable organizer insert for the board game Root. No tests. Original design: FreeCAD `supersketch.FCStd`; current designs: SolidCraft `cards.sc`, `plain.sc`, `divided.sc`, `hireling_cards.sc`, `vagabond_double.sc`; prints and the Bambu project are built by `.bambu/plates.py` (see Printing). `README.md` is the user-facing description (box contents, sizes); keep it in sync when boxes or labels change. Git repo, pushed to GitHub (`gh`).

Each printed box holds one faction/component set and has two removable (suppressible) parts:
- a **wood pocket with a sliding lid**, opening on the ZY plane (holds the wooden pieces);
- a **card slot**, on the XY plane (holds that set's cards).

## How the FreeCAD model is parametrized

`.FCStd` is a zip; `Document.xml` inside holds all objects and expressions (`unzip -p supersketch.FCStd Document.xml`).

- **Spreadsheet `factions`** is the variant table. Its `model` enum property picks a row; row 2 binds that row's values (via `hiddenref(model)`) under aliases. Columns: display name, two-line label (`name 1`/`name 2`, `_` = empty), `t card` (card stack thickness; `0.1 mm` = no cards), `s card` (suppress card slot), `wcard`/`hcard` (card size; `_` hcard = no cards), `t wood` (wood pocket thickness), `slots`, `mini-slots` (fractions like `=1 / 2` are allowed). Rows are grouped by `---` separators: base game/expansions, factions, hirelings/singletons, tokens.
- **VarSet `box`** holds the derived geometry parameters (`wall_thickness`, `height`, `woodbox_width`, `wood_thickness`, `lid_angle`, `lid_thickness`, `lid_delta`, `lid_tolerance`, `text_*`, ...) and the suppress flags (`card_suppress`, `lid_wings1/2/3_suppress`, `text_suppress1/2`). Some are expressions on `factions` (e.g. `card_thickness`, `card_suppress`); sketch constraints reference `<<box>>.<name>`.
- **Bodies:** `box full`, `box half`, `box third` (same feature stack: base block, wood slots/slits, lid wings 1-3, engraved text; size variants) and `lid big` (lid, card pocket, wings pocket). Sketches in the half/third bodies mirror the full body's constraints via expressions like `Sketch003.Constraints[100]`, so edit the `box full` sketches and the others follow.

To change a variant: change `factions.model` (or edit a row) in FreeCAD, recompute, export.

### `root_organizer.sc` — parametric SolidCraft rebuild of `supersketch.FCStd` (deleted)

Deleted from the repo (user, 2026-11-16); it remains in git history. The notes below still describe the recipes the split designs inherited.

- Bodies `Box` (at origin) and `Lid` (at y = `lid_offset` = `W + 30 mm`, so it never overlaps a wide box). Only `box full` + `lid big` were rebuilt; FreeCAD's `box half`/`box third` were identical copies.
- Compartments: `WoodCavity` + `LidSlit` + `LidWings` repeated by `CompartmentPattern`/`WingsPattern` with count `mini_slots`, spacing `pitch` (FreeCAD instead drew 3 fixed rectangles). One lid body = one compartment's lid.
- SolidCraft expressions have no conditionals (`?:`/`if` are rejected), so per-variant logic lives in the **configuration table** (`config.table`, `config.activate {row}`): 37 rows from the `factions` sheet, columns `text0..2`, `slots`, `mini_slots`, `card_t`, `card_h`, `card_w`, `flange_t`, `wood_t`, `top_h`, `side_h`, and suppress `CardPocket`, `TextTop1`, `TextTop2`. Row naming = FreeCAD column A.
- Deliberate differences from FreeCAD: fractional `slots` (2/3, 1/2, 1/3) are honoured (FreeCAD's integer property rounded or broke them); `_` labels suppress the text (FreeCAD engraved underscores); lid flange is centred, width `(W - wall*(n-1))/n - 2*lid_delta` (FreeCAD's was off-centre and overlapped neighbours for n ≥ 2); rows `test`, `std deck`, `exiles partisans`, `squires disciples` (mini-slots 0, unbuildable in FreeCAD too) are not in the table; `t wood` drives `wood_t` (pocket depth, no clearance added; FreeCAD fixed it at 20 mm). Rows whose `t wood` is the `0.1 mm` placeholder keep 20 mm. Top label (faction boxes only, `TextTop2`, one line at `text_h`) is the faction's animal, preferring a word close to the faction name: Corvids, Eagles, Badgers, Skunks, Frogs, Lizards, Rats, Cats, Otters, Bats, Moles, Vagabond (both Vagabond boxes; user changed from Vagabonds), and `Alliance` for Woodland Alliance (user's choice). `TextTop1` (second line, at `text_zx + top_h * 1.6`, height `top_h`) is suppressed in every row; general/hireling boxes have no top label. `dice tokens` side label is `Map Tokens & Dice` (no `+`).
- Printed with a 0.6 mm nozzle (Bambu Lab A1). Hence: all text is DejaVu Sans **Bold** (regular strokes ≈ 0.12 × cap height were < 0.6 mm); `fit` = 0.25 mm sliding clearance per side, applied by the cuts `TongueFit` (dovetail faces, `fit_y = fit / sin(lid_angle)` along y) and `NotchFit` (inner vertical edges of the lid notches). FreeCAD had zero clearance (`lid_tolerance` 0.02 unused). Card and wood pockets get no extra clearance. Cards are in Popcorn Games 63.5 × 88 hard sleeves; `card_t` was measured sleeved (user, 2026-11-16).
- Lid stop (dovetail stop, user wants it kept): `LidWings` (`WingsSketch`) adds a foot at each bottom corner of the lid groove, `wall + lid_wings` (6.5 mm) wide at the bottom, sloping at `lid_angle` up to `wing_h`; the lid has matching `LidNotches` plus `fit` on their vertical edges only (`NotchFit`, a wedge tapering into the slope so there is no step). The slopes touch with zero gap: they carry the lid and keep its bottom flush (a gap on the slope would let it sink 0.5 mm below the box base). Tried a narrow 5 mm block instead; user reverted it.
- 45° chamfers, size `chamfer` (1 mm): `BoxChamfer` (right after `Block`: 4 edges along x + the 4 edges of the x = 0 label face) and `LidChamfer` (right after `LidPlate`: 4 edges of the outer face at max x + 4 flange edges along x). They must stay that early in the timeline: picked after the text/pocket cuts, their edge references include text faces and break in rows where that text or pocket is suppressed.
- Lid height `lid_h` = `height` (100 mm): the closed box is flush on top (FreeCAD used `wood_h`, 3 mm short). `LidPlate`, `TongueFit` and the `CardPocketSketch` plane (XY offset `lid_h`) use it.
- `CardSlot` (`CardSlotSketch` on `LidFacePlane`): U thumb cutout in the lid's outer pocket wall, width `slot_w` (30 mm), depth `slot_d` (38 mm) from the top, cut `wall + card_t / 2` deep; centred on the lid width. Suppressed (table column) wherever `CardPocket` is. The lid label sits beside it at x = `lid_offset + 3 * wall`.
- Merged hireling boxes: rows `A + B` (slots 1, mini_slots 2: two half-width hirelings in one faction-width box, one lid each; the 1/3 hirelings get a 1/2 compartment). `text0` = A on the y = 0 end, `text3` = B on the y = W end (`TextSide2`, suppressed in every other row). Exported as `prints/4N_a__b.3mf` (Box + lid A) and `_lid2.3mf` (lid B); plates.py colours each lid by its hireling. Prosperous Farmers (2/3) and Singletons stay single.
- Lid label (`LidFacePlane` at x = `lid_t + flange_t`, `LidLabelSketch`, cut `LidLabel`): `text0`, centred, reading top to bottom; FreeCAD drew lid ShapeStrings but never cut them. `side_h` (default `text_h`) sized `text0` on both box side and lid (archive only; the split designs use `text_height` and two-line labels).
- Labels and row names use the official Root names (Keepers in Iron, Knaves of the Deepwood, Lord of the Hundreds, Last Dynasty, Eyrie Dynasties); the FreeCAD sheet's spellings were wrong.
- Verified per row: box volume = FreeCAD within ~2 mm³ (underscore text), lid = analytic formula. Text font is "DejaVu Sans" by family name (font file paths are outside the MCP sandbox).
- Work on it in SolidCraft, then `save` to the sandbox and copy back here (or add `--allow-path` as above).
- Superseded by the three split designs (below), which carry later changes (centred text, wing chamfer, `Vagabond` label).

## Printing (Bambu Lab A1, 0.6 mm nozzle)

- `prints/NN_<row>.3mf`: one file per configuration row (Box + Lid), exported from SolidCraft with `config.activate` + `export`.
- Boxes are one of three container types, **factions**, **hireling**, **general** (`TYPES` in `.bambu/plates.py`, which also lists what is printed). Plates are grouped by **colour only** (user, 2026-11-16): same-colour faction parts and hireling lids share a plate. `hirelings 2`/`hirelings 3` are leftovers and are not printed; neither are the separate `Dice` and `Tokens` boxes (user, 2026-11-16: `dice tokens` holds both; rows kept in plain.sc, their prints deleted).
- Colours (`FILAMENTS`, `COLOURS` in `.bambu/plates.py`): official faction/hireling colours from therootdatabase.com/color/<Colour>/, as Bambu PLA Basic. Factions: box + lid in the colour; hirelings: lid only; hireling boxes and Singletons (box + lid): filament 1 `White`; general boxes and lids: `Black` (user, 2026-11-16). Same-colour factions told apart: Riverfolk Cyan vs Eyrie Blue, Lilypad Bright Green vs Alliance Green, Keepers Silver vs Vagabond Gray.
- `root_organizer_A1.3mf`: Bambu Studio project, A1 0.6 nozzle / 0.30mm Standard / Bambu PLA Basic, one colour per plate (18 plates: 2 White, 3 Black + 13 colours; `pack()`: per colour the fewest plates with at most `MAX_PARTS` = 5 parts, parts dealt out evenly, shelves centred on the plate, `LIDS_ONE_PLATE` (Black: all 6 general/Knaves lids on one plate, boxes 2 + 3 on two), rows spread evenly over the plate (equal spaces between parts and to the edges, `MARGIN` 10 mm and `MIN_GAP` 8 mm at least), row length chosen for the widest smallest gap; user, 2026-11-16), each a single filament (object `extruder` = filament index). `orient()` in plates.py turns each part onto the face with the least >45 deg overhang (boxes lie on their back, lids stand upright); Bambu is run with `--orient 0` so it keeps that. 2 lids for `dice tokens`, labelled `Dice` and `Tokens`.
- Lid label = `side_text` in the split designs (was a separate `lid_text` column, always equal; merged 2026-11-16). `dice tokens` has `side_text` 'Dice'; the 'Tokens' lid is exported separately as `prints/04_dice_tokens_lid2.3mf` (set `side_text` to `Tokens`, export `Lid` only, set it back), and `LID_LABELS` in `.bambu/plates.py` puts it on the plate. Rebuild: `python3 .bambu/plates.py prints out.3mf` (shelf-packs onto 256 mm plates, writes `Metadata/model_settings.config` plates and `Metadata/project_settings.config` from `.bambu/*.json` with one filament per `FILAMENTS` entry; without it the Bambu CLI segfaults), then re-save with `flatpak run --command=bambu-studio com.bambulab.BambuStudio --arrange 0 --orient 0 --export-3mf root_organizer_A1.3mf out.3mf`. Check with `--slice 0 --outputdir <dir>` (`; filament: N` in each plate's gcode).
